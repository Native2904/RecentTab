Reset Sort Order

notes/sort-reset/ — note

Problem

Clicking a column header in the panel makes Total Commander sort it independently - regardless of whatever order RecentTab itself intends. If Path then ends up as the active sort column, entries suddenly group alphabetically by folder instead of by date, without anything about the actual content having changed. Looks like a bug in the plugin, but it's TC's own, independent behavior.

Solution

! Reset sort order in the menu brings back RecentTab's own, intended order with one click - newest changes first, exactly as the plugin itself provides them. No need to know TC's own sorting mechanics, no hunting for the right column to Ctrl+click or Shift+click.

Reach

Affects the whole panel, not just whichever subfolder happens to be visible right now - works from inside the menu itself too, even while standing inside ! menu, not just the main view.

  • TC remembers sort order per panel by default, not per folder
  • Changing folders itself has no dedicated storage for the sort method
  • Only a specifically configured "View Mode" rule (not something we use) would separate that per folder
  • So the reset sort order stays in effect even after leaving ! menu

The TC command behind it

cm_SrcUnsorted "Source: Unsorted" - an official internal TC command. "Source" means whichever panel is currently active, "Unsorted" discards any clicked column sort and shows the order the source (here: RecentTab itself) provides. Fired internally the exact same way as cm_RereadSource for the refresh button - no new mechanism, just a different command.

Only affects the panel's display order. Doesn't touch the recording itself, the watched folders, or any stored data.
