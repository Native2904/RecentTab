Reset sorting

notes/sort-reset/ — Handbrief

Problem

Clicking on a column header in the panel causes Total Commander to reorder the list automatically — regardless of the order specified by RecentTab itself. If, for example, the path is then active as the sort column, entries are suddenly grouped alphabetically by folder rather than by date, without any change to the actual content. This may appear to be a bug in the plugin, but it is actually TC’s own, independent behaviour.

Solution

! Sortierung zurücksetzen In the menu, with a single click RecentTabs restores its own, intended order — the most recent changes first, just as the plugin itself displays them. No knowledge of TC’s sorting mechanism is required, and there’s no need to search for the correct column to Ctrl+click or Shift+click on.

Reichweite

Applies to the entire panel, not just the currently visible subfolder — so it also works from within the menu itself, even if you’re currently in ! menu, not in the main view. you don’t have to search for the right column.

  • By default, TC remembers the sort order per panel, not per folder
  • Changing folders does not in itself have its own storage space for the sort method
  • Only a specially configured ‘View Mode’ rule (which we do not use) would separate this by folder
  • That is why the reset sort order remains in place even after exiting ! menu

The command behind

cm_SrcUnsorted "Source: Unsorted" — Official internal TC command. In TC, ‘Source’ refers to the currently active panel; ‘Unsorted’ resets any column sorting that has been applied and displays the order provided by the source (in our case: RecentTab itself). It is triggered internally i. n exactly the same way as cm_RereadSource when the Refresh button is pressed — not a new mechanism, just a different command.

This only affects the display order in the panel. It does not affect the recording, the ‘Watched’ folders or any saved data. Nothing changes in this respect.
